# Implementation Plan

## Goal

提供一套可复现、可审查、不会泄露私人数据的 WorkBuddy → Codex 项目上下文迁移方法。

## Scope

包含项目记忆、全局相关上下文、多个独立历史会话、Codex 项目入口、标题映射、完整性验证和发布安全边界。

不包含多个 Agent 的实时共享记忆、UI 聊天数据库导入和真实用户数据发布。

## Acceptance criteria

- 新用户能根据 README 判断方案是否适合自己；
- 有一份不依赖私人路径的迁移清单示例；
- 有只读盘点脚本；
- 文档明确“原始历史档案”和“目标 Agent 指令”的区别；
- 文档明确 UI 历史记录无法一比一恢复的限制；
- 仓库不包含真实 JSONL、数据库、凭据或私人项目代码；
- 本地 JSON、脚本和链接检查通过。
