# 迁移验证清单

## 来源完整性

- [ ] 来源目录已只读备份。
- [ ] 实际项目与临时任务已区分。
- [ ] 每个项目的顶层会话数量已记录。
- [ ] 原始标题来自稳定的用户/数据库字段，而不是猜测。

## 文件完整性

- [ ] 原始 JSONL 文件名和内容未改变。
- [ ] 迁移前后文件数量和字节数一致。
- [ ] 关键文件 SHA-256 一致。
- [ ] 子 Agent、工具结果和附件范围已记录。

## 目标 Agent 可用性

- [ ] `AGENTS.md` 指向正确的项目根目录。
- [ ] `MEMORY.md` 能索引所有项目记忆主题。
- [ ] 每个历史会话有唯一映射。
- [ ] 每个目标任务保留独立对话，不发生项目级合并。
- [ ] 新对话可以根据索引找到相关历史。

## 隐私与发布

- [ ] 没有 API Key、Token、Cookie 或密码。
- [ ] 没有真实用户画像或私人对话。
- [ ] 没有本机用户名、绝对路径和数据库文件。
- [ ] 没有私有源代码、数据集或实验结果。
- [ ] 示例数据为合成数据。
- [ ] 已加入 `.gitignore` 和安全说明。
