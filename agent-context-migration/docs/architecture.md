# 架构说明

## 四层模型

```text
规范项目数据
├── 项目代码、数据、实验结果
├── 项目记忆与决策记录
├── 原始会话档案
└── Agent 适配层（AGENTS.md、索引、恢复说明）
```

### 规范项目数据

代码和实验结果只有一份，放在用户指定的项目根目录。迁移工具不复制代码，避免 Claude Code、Codex 和云端环境各自出现分叉。

### 项目记忆

保存稳定结论、实验状态、路径约定和待验证事项。用 `MEMORY.md` 做索引，详细内容放在 `memory/` 主题文件中。

### 原始会话档案

原始 JSONL 是证据和历史资料，不是新的 Agent 指令。它应保持只读，并保留来源文件名、顶层会话 ID 和原始标题。

### Agent 适配层

通过 `AGENTS.md` 告诉目标 Agent 先读取哪些文件、如何区分已确认事实和假设，以及如何按需检索历史对话。适配层可以变化，但不应成为唯一知识源。

## 标题来源优先级

```text
用户自定义标题 > 数据库中的稳定标题 > 自动生成标题 > 文件名或 UUID
```

迁移后可在标题末尾追加 `- WorkBuddy` 作为来源标记，但不应覆盖原始标题。
